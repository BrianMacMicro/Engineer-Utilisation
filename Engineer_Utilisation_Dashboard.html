Utilisation settings

Days each engineer worked measures how full their working days were (no leave data is needed, but idle days are not counted). Every weekday assumes each active engineer was available Monday–Friday, so leave, training and sickness pull utilisation down. Actual travel is used only where it was recorded and is between 0 and 5 hours; otherwise the planned travel is used.

Data Quality

Recorded work time is only as good as when engineers start and close jobs. Each job is checked, and any that aren't believable count at their planned time in "actual" utilisation, so late closures don't inflate it.
